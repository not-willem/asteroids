# Debris Game

Created by Sam Hamilton, Julian Pedersen and Willem van Hulst for Kiwihacks Nova

Play it [here](https://not-willem.github.io/debris/)

We created this game in the span of 12 hours with pure HTML. Sam worked on the sound effects and got the soundtrack, Julian did the art and drew everything on paper and I (Willem) did the coding and made it all work good.

Because it was built in pure HTML without any good editors, there is a lot that we missed out on doing and a lot of things that we totally could've added but didn't, like a boss fight which was supposed to be some really big arms that try to steal you and other little things like a scrolling background to make it look like you're in space but due to the time limits we didn't have the time.

Anyway, it was really cool working with people to make a game which is a new experience for me as I usually work alone on games and stuff but it was super fun.

Also we had some technical difficulties, like my computer with 4gb of RAM was crashing because i was trying to run more than 4 programs at a time but we progressed and made a cool project that I actually really enjoy playing.

So go on, [play it](https://not-willem.github.io/debris/) already!
